# 🤖 محاكي المقابلات الشخصية بالذكاء الاصطناعي (AI Interview Simulator)

تطبيق تفاعلي ذكي يُساعد المتقدمين للوظائف على الاستعداد للمقابلات الشخصية واختبار إجاباتهم وتقييمها بأسلوب مبسط وعملي.

---

## 🌟 المميزات الرئيسية
* **تحديد المسمى الوظيفي:** دعم مسارات وظيفية مختلفة (مثل: هندسة البرمجيات، تحليل البيانات، وغيرها).
* **أسئلة تفاعلية:** تقديم أسئلة مقابلة مخصصة لكل مسار وظيفي.
* **تقييم وملاحظات:** مساحة لكتابة الإجابة مع تقديم تغذية راجعة وتقييم فورية.
* **واجهة خفيفة وسريعة:** صُممت باستخدام **Streamlit** لتوفير تجربة مستخدم سلسة.

---

## 🛠️ التقنيات المستخدمة
* **Python** 🐍
* **Streamlit** 🎈
